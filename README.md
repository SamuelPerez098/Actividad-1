# Actividad 1 - Índice de Ejercicios Web

Este proyecto consiste en la modificación y adaptación de los códigos base proporcionados por la profesora para desarrollar una serie de 10 ejercicios web interactivos.

---

##  Modificaciones Realizadas

* **Diseño del Índice (`index.html`):** Adaptación estética con estilo visual inspirado en pergamino tradicional para organizar el acceso a los 10 ejercicios.
* **Estilos y Estructura CSS:** Ajustes en maquetación, paletas de colores, diseño cuadrado/minimalista e integración de imágenes de fondo personalizadas.
* **Lógica en JavaScript:** Actualización y corrección de funciones de cálculo (como la conversión de grados Celsius a Fahrenheit en el Ejercicio 10) e integración de etiquetas para mostrar resultados dinámicos.
* **Publicación Web:** Configuración e integración del repositorio con GitHub Pages para el despliegue del proyecto en línea.
